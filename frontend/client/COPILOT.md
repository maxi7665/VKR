Необходимо создать веб-приложение, которое будет представлять из себя географический сервис.

Стек: vue3 + vuetify + vite.

Функция веб-интерфейса, для начала:

1. Ведение справочника зон (полигонов) - просмотр зон на карте, добавление, редактирование.

Для начала давай сделаем веб-интерфейс, как он может выглядеть. Предполагаю, что слева на экране будет меню, где мы будем перемещаться между разными функциями. Первым нашим пунктом меню будет "Зоны" - справочник геозон.

Сверху будет шапка страницы, на которой указано название приложения - "LYNCEUS"

Справа от меню будет карта, с которой можно взаимодействовать. Знаю, что для vue3 есть обертка openlayers, можно использовать её.

 Для начала сделаем отображение зон на карте. Схема такая: при детализации карты до < 2 км передаем запрос, содержащий координаты видимой области: левый верхний и правый нижний.
