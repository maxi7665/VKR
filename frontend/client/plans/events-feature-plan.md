# План реализации функционала "События" (Events)

## Обзор
Добавление нового пункта меню "События" в приложение LYNCEUS для отображения событий посещения зон в реальном времени через WebSocket.

## Архитектура

```mermaid
graph TD
    A[Пользователь] --> B[App.vue с меню "События"]
    B --> C[EventsTable.vue компонент]
    C --> D[ZoneVisitsWebSocket сервис]
    D --> E[WebSocket /ws-telemetry/zone-visits]
    E --> F[Сервер бэкенда]
    
    F --> G[События посещения зон]
    G --> E
    E --> D
    D --> H[Обработка данных]
    H --> I[Таблица событий]
    I --> J[Новые события сверху]
    J --> K[Ограничение 500 записей]
```

## Компоненты

### 1. TypeScript интерфейсы
```typescript
// src/api/zone-visits.ts
export interface ZoneVisitEvent {
  inOut: 'In' | 'Out';
  deviceId: number;
  vehicleId: number;
  zoneId: number;
  zoneName: string;
  zoneDateTime: string; // ISO 8601 format
}

export interface ZoneVisitsWebSocketCallbacks {
  onOpen?: () => void;
  onClose?: (event: CloseEvent) => void;
  onError?: (error: Event) => void;
  onMessage?: (message: ZoneVisitEvent) => void;
  onReconnect?: (attempt: number) => void;
}
```

### 2. WebSocket сервис (аналогично telemetry.ts)
- Класс `ZoneVisitsWebSocket` с методами connect/disconnect
- Автоматическое переподключение при разрыве
- Обработка сообщений в формате JSON
- URL: `/ws-telemetry/zone-visits`

### 3. Компонент EventsTable.vue
- Структура аналогичная DevicesTable.vue
- Таблица с колонками:
  - Вход/Выход (In/Out) с цветовой индикацией
  - ID устройства
  - ID транспортного средства
  - ID зоны
  - Название зоны
  - Дата и время события (форматированное)
- Реализация ограничения 500 записей
- Новые события добавляются в начало таблицы
- Старые события удаляются снизу при превышении лимита

### 4. Обновление App.vue
- Добавление нового пункта меню "События" с иконкой 📊
- Добавление новой секции в content-panel
- Обновление типа SectionName для TypeScript
- Логика переключения секций

## Поток данных

1. Пользователь нажимает на пункт меню "События"
2. Загружается компонент EventsTable.vue
3. При монтировании компонента создается WebSocket соединение
4. Сервер отправляет события в реальном времени
5. События парсятся и добавляются в начало массива
6. При превышении 500 записей, старые удаляются
7. Таблица автоматически обновляется
8. При переходе на другую секцию WebSocket отключается

## Особенности реализации

### Сортировка данных
- Новые события всегда отображаются сверху (reverse chronological)
- Использование `unshift()` для добавления в начало массива
- Использование `pop()` для удаления старых записей при превышении лимита

### Управление WebSocket
- Соединение устанавливается при монтировании компонента
- Отключение при размонтировании компонента
- Автоматическое переподключение при ошибках
- Индикация состояния соединения

### UI/UX
- Иконка меню: 📊 (график) для событий
- Цветовая индикация: зеленый для "In", красный для "Out"
- Форматирование даты в локальном формате
- Адаптивный дизайн как в DevicesTable.vue
- Индикатор количества событий (X/500)
